# Quick Reference Card

One page. Print it. Full detail in `SKILL.md`.

---

## STEP 0 — ASK BEFORE WRITING (never skip)

1. **Paper type** — molecular · agronomy · omics · method?
2. **Venue** — which journal, or undecided?
3. **Strongest evidence** — which rung (L0–L7), or highest reachable?
4. **Stage** — data in hand · partial · planning only?
5. **Scope** — single claim · full mechanism · discovery+validation · field recommendation?
6. **Constraints** — time, budget, field access, genotypes, equipment?

> Drafting before these are answered produces text that later figures invalidate.

---

## THE LADDER — and the verb you're allowed

| L | Evidence | You may write |
| --- | --- | --- |
| **L0** | Correlation, expression pattern, GWAS/QTL signal | "is associated with" · "correlates with" |
| **L1** | Mutant / knockdown phenotype | "is required for" |
| **L2** | Overexpression, ectopic, inducible | "is sufficient to" |
| **L3** | ≥2 alleles, variant-construct rescue, domain swap | "acts through" |
| **L4** | Y2H, BiFC, Co-IP, in vitro activity | "physically interacts with" |
| **L5** | Epistasis, temporal/tissue-specific rescue | "acts upstream of" |
| **L6** | Ortholog, natural variation, multi-species | "is conserved in" |
| **L7** | Multi-year field trial | "improved ... in the field" |

**The one rule that matters most:** your strongest verb must not exceed your level. Expression data + a mutant phenotype is L1. Write "required for." Never "regulates."

**Evidence moves.** Re-score after every experiment, in both directions. If a control fails, a claim drops — revise the verbs rather than quietly keeping the stronger language.

## VENUE ↔ EVIDENCE MATCH

| Need | Venue family |
| --- | --- |
| **L4+**, convergence of L1–L5 | Nature Plants · Plant Cell · Molecular Plant |
| **L3–L4** | New Phytologist · Plant Physiology · TPJ · JXB · PCE |
| **L1–L2** | BMC Plant Biology · PLoS ONE · Frontiers · Sci Rep |
| **L7**, multi-site-year | Field Crops Research · Agronomy Journal · Crop Science |
| **L0 + validation** | Bioinformatics / computational journals |

**Mismatch is the most avoidable rejection in the field.** Choose the tier your evidence supports, then write the best paper at that tier.

## PLANNING WITH NO DATA — work backwards

```
1. Write the claim you want:  "We show that [X] [acts how] through
   [mechanism] to [trait], and that this [matters why]."
2. Name the venue → 3. Look up its required level
4. List the panels such a paper needs
5. Convert each panel → experiment (design, n, controls, test)
6. Mark the critical path
7. Feasibility check — anything impossible downgrades the claim
8. Revise the claim, return to step 3. Repeat until claim, evidence,
   and venue agree.
```

Never aim a low-evidence project at a high-evidence venue and hope. The gap is a list of experiments — better found now than at review.

## FIGURE ARCHITECTURE (pick one)

**Molecular (6–8):** context → discovery → pattern → necessity → sufficiency → mechanism → order → model
**Agronomy (tables first):** site/soil/weather → ANOVA → trait effect → G×E → response curve → economics
**Omics (6–8):** system → landscape → discovery → structure → signature → **VALIDATION** → functional link → model

> Omics without an independent validation panel is a hypothesis, not a result.

---

## THE FOUR-STATEMENT RULE

Every conclusion appears **four times**: hypothesis (intro/opening) · result (section close) · caption (legend sentence 1) · interpretation (Discussion topic sentence).

---

## DISCUSSION — seven paragraphs, never drop 5 or 6

finding → fit → conflict → mechanism → **alternatives ruled out** → **limitations** → implications

---

## REPORTING THE STANDARD TEST IN EVERY LEGEND

> n (biological vs technical) · error bar definition (SD/SE/95% CI) · statistical test · scale bar for micrographs

**Three wells from one extract is n = 1.**

---

## APPLIED PAPERS — three levels of significance

**Statistical** (is it real?) → **Agronomic** (is it big enough to matter?) → **Economic** (does it pay?)

Stopping at level 1 is the standard grounds for "incremental."

---

## BEFORE SUBMITTING

- [ ] Pre-flight answered · audit re-scored after the final experiment
- [ ] Every abstract causal verb has a figure behind it
- [ ] Discussion has alternatives + limitations paragraphs
- [ ] Accessions, stock IDs, RRIDs present
- [ ] MIQE / MIAPPE / MINSEQE declared where they apply
- [ ] Limits checked in the **current** Guide for Authors
- [ ] No fabricated, reused, or manipulated panels
- [ ] No citation written from memory

---

## NEVER

Fabricate data or images · cite from memory · write "data not shown" · exceed the verb ceiling · report only the marker that worked · submit without accession numbers
